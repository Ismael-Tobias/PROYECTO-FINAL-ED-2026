ENCAPSULACIÓN

1

¿QUE ES LA ENCAPSULACIÓN?

La encapsulación en Java es un principio fundamental de la programación orientada a objetos que consiste en agrupar los datos (variables) y los métodos que operan sobre dichos datos dentro de una sola unidad denominada clase. Este mecanismo permite definir con claridad cómo se accede y se modifica la información de un objeto. La encapsulación se logra declarando las variables como privadas (private) y proporcionando métodos públicos conocidos como getters y setters, a través de los cuales se controla el acceso a los datos. De esta manera, los campos de un objeto permanecen ocultos para otras clases y solo pueden ser consultados o modificados mediante operaciones bien definidas. Este principio actúa como una barrera de protección, evitando accesos directos o modificaciones indebidas de la información. La encapsulación no solo busca ocultar los datos, sino también controlar su acceso y validación, lo que contribuye a la seguridad, mantenibilidad y correcta organización del código.

Terminal 
> Ejemplo de Encapsulación

public class Alumno {
    // Datos encapsulados
    private String nombre;
    private int edad;

    public String getNombre()
    {
        return nombre;
    }
    public int getEdad() 
    {
        return edad;
    }
    public void setNombre(String nombre)
    {
        this.nombre = nombre;
    }
    public void setEdad(int edad) 
    {
        if (edad > 0) { // Validación
            this.edad = edad;
        }
    }

    public static void main(String[] args) {
        Alumno alumno1 = new Alumno();
        alumno1.setNombre("Carlos");
        alumno1.setEdad(18);

        System.out.println("Nombre: " + alumno1.getNombre());
        System.out.println("Edad: " + alumno1.getEdad());
    }
}

¿COMO LOGRAR LA ENCAPSULACIÓN?

Para implementar la encapsulación en Java, se deben seguir los siguientes pasos:

1) Declarar las variables como private, con el fin de restringir el acceso directo a los atributos de la clase desde otras clases.

2) Proporcionar métodos públicos (public), conocidos como getters y setters, que permitan acceder y actualizar de forma controlada el valor de los atributos. Mediante este procedimiento, Java garantiza que los datos de un objeto estén protegidos y solo puedan ser manipulados a través de métodos bien definidos, lo que contribuye a un diseño de software más seguro, organizado y fácil de mantener.

3

TIPOS DE ENCAPSULACIÓN

La encapsulación puede aplicarse en distintos niveles, dependiendo del alcance del control de acceso que se desee establecer. A continuación, se describen los principales tipos:

1. Encapsulación a nivel de miembro: Es la forma más básica y común de encapsulación en Java. Consiste en declarar los campos de una clase como private y permitir el acceso a ellos únicamente mediante métodos públicos, conocidos como getters y setters. Esto garantiza que los atributos no puedan ser modificados directamente desde el exterior.

2. Encapsulación a nivel de clase: Este tipo de encapsulación se logra manteniendo las clases dentro de un paquete sin declararlas como public. De esta manera, el acceso a dichas clases queda restringido únicamente a otras clases que se encuentren dentro del mismo paquete, evitando su uso desde paquetes externos.

3. Encapsulación a nivel de paquete: En Java, el uso de modificadores de acceso como protected o la ausencia de un modificador (acceso por defecto) permite restringir el acceso a clases o miembros para que solo puedan ser utilizados dentro del mismo paquete o por clases relacionadas. Esto contribuye a una mejor organización y protección del código.
