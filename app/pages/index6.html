COLAS

1

¿QUÉ ES UNA COLA?

Una cola es una estructura de datos lineal que permite almacenar y administrar elementos siguiendo el principio FIFO (First In, First Out), lo que significa que el primer elemento que se inserta es también el primero en ser eliminado. Este comportamiento garantiza que los datos se procesen en el mismo orden en que fueron agregados. En una cola, los elementos se añaden por un extremo denominado final, mientras que la eliminación se realiza por el extremo opuesto llamado frente. Esta organización evita accesos desordenados y proporciona un control eficiente del flujo de información. Las colas son ampliamente utilizadas en el desarrollo de software, especialmente en situaciones donde es necesario respetar el orden de llegada de los datos, como en la gestión de tareas, el manejo de solicitudes, la administración de procesos y el funcionamiento de sistemas de espera.

Terminal 
>public class Cola {
    private int[] cola;
    private int frente;
    private int fin;
    private int tamaño;

    public Cola(int capacidad) {
        cola = new int[capacidad];
        frente = 0;
        fin = -1;
        tamaño = 0;
    }

    // Insertar elemento (enqueue)
    public void encolar(int dato) {
        if (tamaño == cola.length) {
            System.out.println("La cola está llena");
            return;
        }
        fin++;
        cola[fin] = dato;
        tamaño++;
    }

    // Eliminar elemento (dequeue)
    public int desencolar() {
        if (tamaño == 0) {
            System.out.println("La cola está vacía");
            return -1;
        }
        int dato = cola[frente];
        frente++;
        tamaño--;
        return dato;
    }

    // Mostrar el primer elemento
    public int frente() {
        return cola[frente];
    }

    // Método principal
    public static void main(String[] args) {
        Cola c = new Cola(5);

        c.encolar(10);
        c.encolar(20);
        c.encolar(30);

        System.out.println("Sale: " + c.desencolar());
        System.out.println("Sale: " + c.desencolar());
        System.out.println("Frente actual: " + c.frente());
    }
}
2

FUNCIONAMIENTO DE COLA

El funcionamiento de una cola se basa en un acceso controlado a los datos, donde los elementos se procesan en el mismo orden en que fueron ingresados. Cuando un nuevo elemento llega, se agrega al final de la cola, y cuando se necesita retirar uno, se elimina el que se encuentra en el frente. Este mecanismo permite un flujo ordenado de información y evita que los datos se salten posiciones, lo que resulta útil en sistemas que manejan procesos de manera secuencial. La cola mantiene siempre un punto inicial y uno final, lo que facilita la gestión eficiente de los elementos durante la ejecución de un programa.

3

OPERACIONES BÁSICAS DE UNA COLA

- Insertar (enqueue): agrega un elemento al final de la cola. - Eliminar (dequeue): retira el elemento que se encuentra al frente. - Consultar frente (peek): permite visualizar el primer elemento sin eliminarlo. - Verificar si está vacía: comprueba si la cola contiene elementos. - Obtener tamaño: indica cuántos elementos hay almacenados.

4

VENTAJAS

- Mantiene el orden de llegada de los elementos, garantizando un procesamiento justo y organizado. - Facilita la gestión de tareas secuenciales, como solicitudes, procesos o eventos. - Permite un control eficiente del flujo de datos, evitando accesos desordenados. - Es sencilla de implementar y comprender, incluso en aplicaciones complejas. - Mejora la organización del código, haciendo que los programas sean más claros y mantenibles.

5

DESVENTAJAS

- El acceso a los elementos es limitado, ya que solo se puede interactuar con el frente y el final. - No permite acceder directamente a un elemento específico sin eliminar los anteriores. - Puede presentar desperdicio de memoria si no se implementa correctamente, especialmente en colas simples. - Su uso no es adecuado cuando se requiere acceso aleatorio a los datos.
