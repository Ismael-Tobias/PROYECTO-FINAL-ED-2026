PILAS

1

¿Qué es una pila?

Una pila es una estructura de datos lineal que permite almacenar y organizar información siguiendo el principio LIFO (Last In, First Out), lo que significa que el último elemento añadido es el primero en ser eliminado. Este modelo de funcionamiento garantiza un control ordenado de los datos, ya que todas las operaciones se realizan desde un único punto denominado tope. Las pilas admiten operaciones básicas como la inserción de elementos (push), la eliminación del elemento superior (pop) y la consulta del valor almacenado en el tope (peek), sin modificar su contenido. Estas operaciones se caracterizan por su rapidez y simplicidad, lo que hace a las pilas eficientes en términos de tiempo de ejecución.

Terminal 
> public class Pila {
    private int[] elementos;
    private int tope;
    public Pila(int capacidad) {
        elementos = new int[capacidad];
        tope = -1;
    }

    // Insertar elemento (push)
    public void push(int dato) {
        if (tope == elementos.length - 1) {
            System.out.println("La pila está llena");
        } else {
            elementos[++tope] = dato;
            System.out.println("Elemento insertado: " + dato);
        }
    }

    // Eliminar elemento (pop)
    public int pop() {
        if (tope == -1) {
            System.out.println("La pila está vacía");
            return -1;
        } else {
            return elementos[tope--];
        }
    }

    // Mostrar elemento superior (peek)
    public int peek() {
        if (tope == -1) {
            System.out.println("La pila está vacía");
            return -1;
        } else {
            return elementos[tope];
        }
    }

    public static void main(String[] args) {

        Pila pila = new Pila(5);

        pila.push(10);
        pila.push(20);
        pila.push(30);

        System.out.println("Elemento en la cima: " + pila.peek());
        System.out.println("Elemento eliminado: " + pila.pop());
        System.out.println("Nueva cima: " + pila.peek());
    }
}
2

FUNCIONAMIENTO DE PILA

El funcionamiento de una pila se basa en un acceso ordenado a los datos, donde todas las operaciones se realizan desde un único punto llamado tope. Los elementos se van agregando uno sobre otro, y solo el último elemento ingresado puede ser consultado o eliminado, lo que permite mantener un control claro de la información almacenada. Cuando se inserta un elemento en la pila, este pasa a ocupar el tope de la estructura. Al eliminar un elemento, se retira únicamente el que se encuentra en esa posición. También es posible consultar el valor del elemento superior sin modificar el contenido de la pila, lo cual resulta útil para conocer su estado actual. Este tipo de funcionamiento hace que las pilas sean eficientes en situaciones donde se requiere seguir un orden específico, como la ejecución de procesos, el manejo de operaciones temporales y el control del flujo dentro de un programa

Terminal 
>public class Pila {
    private int[] pila;
    private int tope = -1;

    public Pila(int tamaño) {
        pila = new int[tamaño];
    }

    public void push(int valor) {
        if (tope < pila.length - 1)
            pila[++tope] = valor;
    }

    public int pop() {
        return (tope >= 0) ? pila[tope--] : -1;
    }

    public static void main(String[] args) {
        Pila p = new Pila(3);
        p.push(5);
        p.push(10);
        p.push(15);

        System.out.println(p.pop());
        System.out.println(p.pop());
        System.out.println(p.pop());
    }
}
3

OPERACIONES BÁSICAS DE UNA PILA

Insertar (push): agrega un elemento en el tope. Eliminar (pop): retira el elemento superior. Consultar el tope (peek): muestra el elemento superior sin eliminarlo. Verificar si está vacía: comprueba si la pila contiene elementos.

4

VENTAJAS

- Son fáciles de implementar. - Permiten un control ordenado de los datos. - Sus operaciones son rápidas y eficientes. - Reducen errores al limitar el acceso a los elementos.

5

DESVENTAJAS

- No permiten acceso directo a todos los elementos. - Solo se puede trabajar con el elemento del tope. - En pilas estáticas, el tamaño es limitado.
