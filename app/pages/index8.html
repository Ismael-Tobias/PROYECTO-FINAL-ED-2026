¿QUÉ ES?

Los árboles en Java son estructuras de datos jerárquicas utilizadas para organizar información de manera eficiente. A diferencia de listas o arreglos, los árboles permiten representar relaciones entre elementos mediante nodos conectados.

2

Se utilizan en :

* Sistemas de archivos * Bases de datos * Inteligencia artificial * Navegadores web (DOM) * Compiladores * Algoritmos de búsqueda

Terminal 
import java.util.Scanner;
class Nodo {
    int dato;
    Nodo izq, der;
    public Nodo(int dato) {
        this.dato = dato;
        izq = der = null;
    }
}
class Arbol {
    Nodo raiz;
    public Nodo insertar(Nodo raiz, int dato) {
        if (raiz == null) {
            return new Nodo(dato);
        }
        if (dato < raiz.dato) {
            raiz.izq = insertar(raiz.izq, dato);
        } else if (dato > raiz.dato) {
            raiz.der = insertar(raiz.der, dato);
        }
        return raiz;
    }
    public void inorden(Nodo raiz) {
        if (raiz != null) {
            inorden(raiz.izq);
            System.out.print(raiz.dato + " ");
            inorden(raiz.der);
        }
    }
    public boolean buscar(Nodo raiz, int dato) {
        if (raiz == null) {
            return false;
        }
        if (raiz.dato == dato) {
            return true;
        }
        if (dato < raiz.dato) {
            return buscar(raiz.izq, dato);
        } else {
            return buscar(raiz.der, dato);
        }
    }
    public void mostrarBonito(Nodo raiz) {
        if (raiz == null) {
            System.out.println("Árbol vacío");
            return;
        }
        System.out.println("\n" + raiz.dato);
        if (raiz.izq != null || raiz.der != null) {
            System.out.println("      /   \\");
        }

        if (raiz.izq != null) {
            System.out.print("" + raiz.izq.dato);
        } else {
            System.out.print("      ");
        }
        if (raiz.der != null) {
            System.out.println("" + raiz.der.dato);
        }
        if (raiz.izq != null &&
            (raiz.izq.izq != null || raiz.izq.der != null ||
             raiz.der != null && raiz.der.der != null)) {

            System.out.println("    / \\      \\");
        }
        if (raiz.izq != null && raiz.izq.izq != null) {
            System.out.print("   " + raiz.izq.izq.dato);
        }
        if (raiz.izq != null && raiz.izq.der != null) {
            System.out.print("   " + raiz.izq.der.dato);
        }
        if (raiz.der != null && raiz.der.der != null) {
            System.out.print("      " + raiz.der.der.dato);
        }
        System.out.println();
    }
}
public class Main {
    public static void main(String[] args) {
        Scanner leer = new Scanner(System.in);
        Arbol arbol = new Arbol();
        int op, dato;
        do {
            System.out.println("""           
                    ===== MENU =====
                    1. Insertar nodo
                    2. Mostrar árbol
                    3. Recorrido Inorden
                    4. Buscar número
                    5. Salir
                    """);
            System.out.print("Opción: ");
            op = leer.nextInt();
            switch (op) {
                case 1:
                    System.out.print("Ingresa número: ");
                    dato = leer.nextInt();
                    arbol.raiz = arbol.insertar(arbol.raiz, dato);
                    break;
                case 2:
                    arbol.mostrarBonito(arbol.raiz);
                    break;
                case 3:
                    System.out.println("\nRecorrido Inorden:");
                    arbol.inorden(arbol.raiz);
                    System.out.println();
                    break;
                case 4:
                    System.out.print("Número a buscar: ");
                    dato = leer.nextInt();
                    if (arbol.buscar(arbol.raiz, dato)) {
                        System.out.println("Sí existe");
                    } else {
                        System.out.println("No existe");
                    }
                    break;
                case 5:
                    System.out.println("Programa terminado");
                    break;
                default:
                    System.out.println("Opción inválida");
            }
        } while (op != 5);
    }
}

Elementos principales de un árbol:

* Nodo: elemento que almacena información. * Raíz: nodo principal del árbol. * Padre: nodo que tiene hijos. * Hijo: nodo conectado debajo de otro. * Hoja: nodo sin hijos. * Arista: conexión entre nodos.

4

CARACTERISTICA

* Existe un único camino desde la raíz hasta cualquier nodo. * No existen ciclos. * Permite representar relaciones jerárquicas.

4

Un árbol de búsqueda binario (BST)

Es un árbol binario donde cada nodo tiene un valor mayor que todos los valores en su subárbol izquierdo y menor que los de su subárbol derecho. Esta propiedad hace que los BST sean adecuados para operaciones eficientes de búsqueda, inserción y eliminación.

UN ARBOL AVL

Es un árbol de búsqueda binaria autoequilibrado. Mantiene el equilibrio asegurando que la diferencia de altura entre los subárboles izquierdo y derecho de cualquier nodo no sea más de uno. Esta condición de equilibrio se mantiene a través de rotaciones durante las inserciones y eliminaciones.

4

UN ARBOL BINARIO

Un árbol binario es una estructura de datos no lineal utilizada en programación y ciencias computacionales para organizar información de manera jerárquica. Está compuesto por nodos conectados entre sí mediante enlaces llamados aristas, donde cada nodo puede tener como máximo dos hijos: uno izquierdo y uno derecho. A diferencia de estructuras lineales como arreglos o listas enlazadas, los árboles binarios permiten representar relaciones jerárquicas y realizar operaciones de búsqueda, inserción y eliminación de manera más eficiente.

Terminal 
import java.util.Scanner;
class Nodo {
    int dato, altura;
    Nodo izq, der;
    public Nodo(int dato) {
        this.dato = dato;
        altura = 1;
    }
}
class AVL {
    Nodo raiz;
    int altura(Nodo n) {
        if (n == null) {
            return 0;
        }
        return n.altura;
    }
    int balance(Nodo n) {

        if (n == null) {
            return 0;
        }

        return altura(n.izq) - altura(n.der);
    }
    Nodo rotarDerecha(Nodo y) {
        Nodo x = y.izq;
        Nodo t2 = x.der;
        x.der = y;
        y.izq = t2;
        y.altura = Math.max(altura(y.izq), altura(y.der)) + 1;
        x.altura = Math.max(altura(x.izq), altura(x.der)) + 1;
        return x;
    }
    Nodo rotarIzquierda(Nodo x) {
        Nodo y = x.der;
        Nodo t2 = y.izq;
        y.izq = x;
        x.der = t2;
        x.altura = Math.max(altura(x.izq), altura(x.der)) + 1;
        y.altura = Math.max(altura(y.izq), altura(y.der)) + 1;
        return y;
    }
    Nodo insertar(Nodo nodo, int dato) {
        if (nodo == null) {
            return new Nodo(dato);
        }
        if (dato < nodo.dato) {
            nodo.izq = insertar(nodo.izq, dato);
        } else if (dato > nodo.dato) {
            nodo.der = insertar(nodo.der, dato);
        } else {
            return nodo;
        }
        nodo.altura = 1 + Math.max(altura(nodo.izq), altura(nodo.der));}
        int balance = balance(nodo);
        // IZQUIERDA IZQUIERDA
        if (balance > 1 && dato < nodo.izq.dato) {
            return rotarDerecha(nodo);
        }
        if (balance < -1 && dato > nodo.der.dato) {
            return rotarIzquierda(nodo);
        }
        if (balance > 1 && dato > nodo.izq.dato) {

            nodo.izq = rotarIzquierda(nodo.izq);

            return rotarDerecha(nodo);
        }
        if (balance < -1 && dato < nodo.der.dato) {
            nodo.der = rotarDerecha(nodo.der);
            return rotarIzquierda(nodo);
        }
        return nodo;
    }
    void mostrarBonito() {
        if (raiz == null) {
            System.out.println("Árbol vacío");
            return;
        }
        System.out.println("\n    " + raiz.dato);
        if (raiz.izq != null || raiz.der != null) {
            System.out.println("   /  \\");
        }
        if (raiz.izq != null) {
            System.out.print(" " + raiz.izq.dato);
        }
        if (raiz.der != null) {
            System.out.println("   " + raiz.der.dato);
        }
        System.out.println();
    }

    public static void main(String[] args) {
