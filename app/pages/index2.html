MODULO

Los modelos de programación son abstracciones que definen la manera en que se estructuran, organizan y ejecutan las instrucciones dentro de una computadora. Estos modelos establecen las bases para el diseño y desarrollo de software, facilitando la comprensión y el control del flujo de ejecución de los programas. Los enfoques de programación varían desde la programación secuencial, paralela y modular, hasta la programación orientada a objetos (POO). Cada uno de estos enfoques permite a los desarrolladores seleccionar el modelo técnico que mejor se adapte a los requerimientos del sistema, considerando factores como la eficiencia, la escalabilidad y el nivel de complejidad del software a desarrollar.

Terminal 
> Ejemplo de Modularidad

public class ModuloEjemplo {
    public static void mostrarMensaje()
    {
        System.out.println("Bienvenido al sistema");
    }
    public static int sumar(int a, int b) 
    {
        return a + b;
    }
    public static boolean esPar(int numero)
    {
        return numero % 2 == 0;
    }
    public static void main(String[] args)
    {
        mostrarMensaje();
        int resultado = sumar(8, 4);
        System.out.println("Resultado de la suma: " + resultado);
        boolean par = esPar(resultado);
        System.out.println("¿El resultado es par? " + par);
    }
}

ABSTRACCION DE DATOS

La abstracción de datos es un principio fundamental en la programación que consiste en separar la definición lógica de un conjunto de datos de su implementación concreta. Un tipo abstracto de datos (TAD) es aquel cuya representación interna ha sido ocultada, permitiendo que los datos solo puedan ser manipulados mediante un conjunto específico de operaciones previamente definidas. Este enfoque facilita el desarrollo de programas más claros y seguros, ya que el usuario del tipo abstracto de datos no necesita conocer los detalles de su implementación interna. Además, la abstracción de datos favorece la reutilización del código, el mantenimiento del software y la reducción de errores, al limitar el acceso directo a los datos y promover el uso de interfaces bien definidas.

Terminal 
> Ejemplo de Abstraccion de Datos

public class CuentaBancaria {
    private double saldo;
    public CuentaBancaria(double saldoInicial) {
        saldo = saldoInicial;
    }
    public double obtenerSaldo() {
        return saldo;
    }
    public void depositar(double cantidad) {
        if (cantidad > 0) {
            saldo += cantidad;
        }
    }
    public void retirar(double cantidad){
        if (cantidad > 0 && cantidad = saldo) {
            saldo -= cantidad;
        }
    }
    public static void main(String[] args){
        CuentaBancaria cuenta = new CuentaBancaria(1000);
        cuenta.depositar(500);
        cuenta.retirar(300);
        System.out.println("Saldo actual: $" + cuenta.obtenerSaldo());
    }
}

CLASE

Una clase es un modelo o plano que define los datos y comportamientos que tendrán los objetos que se crean a partir de ella. En una clase se agrupan los campos (atributos) y los métodos (funciones) relacionados, formando una sola unidad que facilita la organización y estructura del código. La memoria para los miembros de una clase se asigna únicamente cuando se crea un objeto a partir de dicha clase. Esto permite un uso eficiente de los recursos del sistema y posibilita la creación de múltiples objetos independientes que comparten la misma definición, pero mantienen su propio estado en memoria.

Terminal 
> Ejemplo de una Clase

public class Persona {
    String nombre;
    int edad;

    // Método 
    void saludar() {
        System.out.println("Hola, mi nombre es " + 
        nombre + " y tengo " + edad + " años.");
    }
    public static void main(String[] args) {
        Persona persona1 = new Persona();
        persona1.nombre = "Ana";
        persona1.edad = 20;
        persona1.saludar();
    }
}

OBJETO

Un objeto es una entidad que representa una encapsulación de un estado y un comportamiento. El estado de un objeto está definido por los valores que toman sus datos o atributos, mientras que el comportamiento se expresa a través de las operaciones o métodos que puede realizar. Los objetos se crean a partir de una clase y permiten modelar elementos del mundo real dentro de un programa. Cada objeto posee su propio estado en memoria y puede interactuar con otros objetos mediante la ejecución de sus métodos, lo que facilita la construcción de sistemas estructurados, reutilizables y fáciles de mantener.

> Ejemplo de instanciamiento de un objeto

LEGUAJES DE PROGRAMACION

Los lenguajes de programación ofrecen distintos niveles de abstracción, los cuales dependen de los mecanismos y herramientas que proporciona cada lenguaje. Estos niveles permiten al desarrollador elegir la forma más adecuada de organizar y estructurar un programa, de acuerdo con la complejidad del sistema y los servicios que se desean implementar. Desde la perspectiva funcional, los lenguajes de programación pueden basarse en elementos como el ensamblador, los procedimientos y los módulos, los cuales se enfocan en la secuencia y control de las operaciones que ejecuta el programa. Desde la perspectiva de datos, se utilizan mecanismos como los paquetes y los tipos abstractos de datos (TAD), que permiten organizar y proteger la información, separando su definición lógica de su implementación. Finalmente, desde la perspectiva de servicio, se emplean los objetos, los cuales extienden el concepto de los TAD al incorporar características como el paso de mensajes, la herencia y el polimorfismo, facilitando el desarrollo de sistemas más flexibles, reutilizables y escalables.
