¿Qúe es una estructura de datos?

Una estructura de datos es un método utilizado para organizar y almacenar información en la memoria de la computadora y, en algunos casos, en medios de almacenamiento secundario como el disco. Su propósito principal es permitir el acceso, la gestión y la manipulación eficiente de los datos dentro de un sistema informático. Entre las estructuras de datos más utilizadas se encuentran los arreglos (arrays), las listas enlazadas, las pilas (stack), las colas (queue), los árboles binarios y las tablas de dispersión. Cada una de estas estructuras se emplea de acuerdo con las necesidades del programa y el tipo de operaciones que se requieran realizar, contribuyendo a un uso más eficiente de la memoria y a un mejor desempeño de los algoritmos.

Terminal 
> Ejemplo de Estructura de Datos

import java.util.*;

public class EjemploLista {

    public static void main(String[] args) {

        int[] lista = {10,20,30};

        System.out.println(lista[1]);

    }
}

ESTRUCTURAS DE DATOS LINEALES

Las estructuras de datos lineales son aquellas en las que los elementos se organizan en una sola dimensión, también conocida como dimensión lineal. En este tipo de estructuras, los datos se almacenan de forma secuencial, lo que permite que cada elemento tenga un único elemento anterior y uno posterior, excepto el primero y el último. Entre los ejemplos más representativos de las estructuras de datos lineales se encuentran los arreglos (array), las listas enlazadas, las pilas (stack), que siguen el principio LIFO (último en entrar, primero en salir), y las colas (queue), que funcionan bajo el principio FIFO (primero en entrar, primero en salir). Estas estructuras son ampliamente utilizadas en programación debido a su simplicidad y eficiencia en el manejo de datos secuenciales.

Terminal 
> Estructura lineal

public class Lineal{
    public static void main(String[] args){
        String arreglo[] = {"Ismael", "Miranda", "Fatima"}
        //Resultado
        System.out.println(arreglo[1])
    }
}

ESTRUCTURAS DE DATOS NO LINEALES

Las estructuras de datos no lineales son aquellas en las que los datos no se organizan de forma secuencial, sino que establecen relaciones más complejas entre sus elementos, como uno a muchos o muchos a muchos. En este tipo de estructuras, un elemento puede estar conectado con varios otros, lo que permite representar jerarquías y redes de información de manera más flexible. Entre los principales ejemplos de estructuras de datos no lineales se encuentran las tablas, los árboles (tree), los grafos (graphs), los montículos (heaps) y los árboles prefijos (tries). Estas estructuras son ampliamente utilizadas para modelar relaciones complejas, optimizar búsquedas y gestionar grandes volúmenes de información de forma eficiente dentro de los sistemas informáticos.

Terminal 
> Estructura no lineal

class Nodo{
    int valor;
    Nodo izquierda, derecha;
    //Constructor
    public Nodo(int valor){
        this.valor = valor;
    }
}
public class ArbolSimple{
    public static void main(String[] args){
        Nodo raiz = new Nodo(10);
        raiz.izquierda = new Nodo(5);
        raiz.derecha = new Nodo(20);
        //Imprecion de Resultados
        System.out.println("Raiz: " + raiz.valor);
        System.out.println("Hijo izquierdo: " + raiz.izquierda.valor);
        System.out.println("Hijo derecho: " + raiz.derecha.valor);
    }
}
